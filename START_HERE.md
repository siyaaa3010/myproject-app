## 🚨 **TROUBLESHOOTING**

### Music doesn't play?
- Click the Play button manually
- Some browsers block autoplay

### Photos don't show?
- Check `public/newPhotos/` has all 44 photos
- Check file names: 1.jpg through 44.jpg

### Want to reset?
```javascript
localStorage.clear()
```
Run in browser console (F12)
